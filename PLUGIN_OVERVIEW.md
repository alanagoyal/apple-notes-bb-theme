my apple notes theme for bb, with a gold accent, dated threads, and a note-style
writing space.

## using it

- choose light or dark with the included palette.
- press `/` to search by thread title or project.
- browse date groups and write on a blank note.
- drop attachments anywhere in the thread pane.
- use draft phrases to select projects, machines, and models available in bb.
- press cmd/ctrl + shift + l to switch light and dark modes.

## how it works

it keeps bb's native threads, composer, timeline, menus, shortcuts, and plugin
contributions. the theme adds the layout, search, dates, and headings. search
covers titles and project names, not messages.

the included palette applies the layout before the plugin starts.

## setup

requires bb 0.46.1 or newer, plugin sdk 0.6.49 or newer, and git. the plugin doesn't
need an extra account or paid service. bb updates may need small fixes to the
css selectors or experimental sdk hooks.

source, setup, and the mit license are on
[github](https://github.com/alanagoyal/apple-notes-bb-theme).
